# Guia Definitivo — De Iniciante a UGC

Página de vendas do produto digital **"Guia Definitivo — De Iniciante a UGC"**, voltado para mulheres que querem começar a ganhar de R$100 a R$500 por vídeo criando conteúdo (UGC) para marcas.

## Sobre o projeto

Página única em HTML/CSS/JS (sem frameworks), com:

- Duas opções de plano: **Básico** (R$9,90) e **Premium** (R$19,90)
- Seção de prova social com prints de pagamento e vídeos de conteúdo entregue a marcas
- Comparativo de planos
- Seção "Sobre" com apresentação da criadora
- Carrossel de depoimentos em vídeo e print de alunas embaixadoras
- Seção de FAQ, garantia e CTA final

## Arquivos

- `index.html` — a página completa, pronta para publicar (todo o CSS e JS estão dentro do próprio arquivo).

## Como publicar

**Opção 1 — GitHub Pages (grátis, com link público)**
1. Depois de subir este repositório, vá em **Settings → Pages**.
2. Em "Source", selecione a branch `main` e a pasta `/ (root)`.
3. Salve. Em alguns minutos o GitHub te dá um link tipo `https://seu-usuario.github.io/nome-do-repositorio/`.

**Opção 2 — Hospedar em outro lugar**
Basta pegar o `index.html` e subir em qualquer serviço de hospedagem ou no seu construtor de site.

## Observação

Os vídeos das seções "Conteúdo para marcas" e "Depoimentos" estão hospedados no Vimeo e incorporados via iframe — não fazem parte deste repositório.
